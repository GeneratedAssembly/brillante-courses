# Images

Figures extracted from the two course sources live here. Naming and citation
rules (enforced by the final citation audit):

- `mit-lec<N>-<fig>.png` — figures excerpted from MIT OCW 2.71 lecture notes.
  The lesson caption must end with:
  `(Source: MIT OCW 2.71 Optics, Spring 2009, lecture <N>, CC BY-NC-SA 4.0 — https://ocw.mit.edu/courses/2-71-optics-spring-2009/)`
- `openstax-<ch>-<fig>.png` — figures excerpted from OpenStax University
  Physics III. The lesson caption must end with:
  `(Source: OpenStax University Physics III, section <ch>.<s>, CC BY 4.0 — https://openstax.org/details/books/university-physics-volume-3)`

Prefer linking out over copying. Copy only figures that are genuinely needed
inline, always with a citation caption.
